Conectar con nabnab

  1. Copia este ID de extensión y pégalo en nabnab, Ajustes > Navegador.
  2. Genera un token en la aplicación y pégalo aquí.

Selecciona el ID y cópialo con Ctrl+C.

nabnab debe estar abierto. El token se guarda solo en el almacenamiento local de esta extensión.

Revoca también el cliente en la aplicación para invalidar el token. La extensión solo envía los enlaces que eliges; no lee cookies ni intercepta tu navegación.
