# nabnab 0.2.0

More sources, local tools and a refined interface, with downloads and results kept in the common queue and library.

## Changes

- A full-height, more transparent sidebar and a brighter character field with finer moving detail. Ambient color waves run every 25 seconds; ten emblem activations toggle overlapping continuous waves. Reduced-motion and reduced-transparency preferences remain available. Home keeps a single Import action, and every specialized platform view has a route back to the catalog.
- A platform catalog with attachment selection, optional gallery-dl, gallery following, local HTML galleries and contact sheets. Pasted social posts open attachment selection and retain an explicit video-only route.
- Additional video/audio providers, podcast RSS subscriptions with OPML/M3U, source exports, federated attachments, and bounded YouTube/Twitch live-recording support.
- Optional aria2 for advanced HTTP transfers and BitTorrent file selection. P2P requires explicit activation and stops seeding after download by default.
- Optional TDLib 1.8.69, protected account configuration and authorized Telegram attachment selection. The native package has a fixed source, size and SHA-256; installation does not authorize an account.
- Separate course adapters and local study organization, with lesson progress, materials and notes.
- Multilingual local transcription, caption editing/synchronization, GIF/WebP, image conversion, clip joining, audio replacement, subtitle burning, audio preview, palette export, and optional PDF/EPUB tools.
- The Chrome/Edge extension can detect candidate media on the explicitly selected page and send it through the paired desktop bridge.

## Download and upgrade

Use `nabnab_0.2.0_x64-setup.exe` for Windows x64. Installation is per user and requires WebView2. The installer is unsigned. Updating from ytnabber retains the existing installation folder and application data. Optional engines and speech models download only when requested.

`nabnab-browser-extension_0.2.0.zip` contains the Chrome/Edge extension. Extract it and follow the [pairing and installation instructions](https://github.com/Hakaelll/nabnab/blob/v0.2.0/docs/BROWSER.md). It is not installed automatically.

`SHA256SUMS.txt` records checksums for the downloadable packages. The installer SHA-256 is `b0daa5fdae2e30e81f5f9b904bf1b03e414e9851d2c9cbb854eecd7ecbbd9cdf`.

## Verification and limits

- Production build and engine manifest/integrity verification passed. The installer contains yt-dlp 2026.10.26, Deno 2.9.8 and FFmpeg 9.0.2 with WebP and libass support.
- 27 JavaScript tests and 224 native tests passed. Another 25 native integrations are conditional and ignored by default; this does not certify external services.
- Browser fixture checks cover 900, 1180 and 1280 pixel windows, 125%/150% scaling, keyboard focus, reduced motion/transparency and a 1000-item library. A focused regression reproduced the missing return control before the fix and passed afterward across the catalog, specialized modules and sidebar navigation. The simplified Import row was checked in the same run.
- Real synthetic-file checks exercised FFmpeg tools, static/animated WebP, subtitle burning, MuPDF, gallery exports, media composition, palettes, audio preview and aria2 HTTP transfer.
- Native tests installed and disabled TDLib without authorizing an account, loaded its 1.8.69 schema locally, and rejected a tampered package. A Spanish synthetic speech fixture passed actual Whisper transcription, queue publication and library search.
- A real per-user upgrade from ytnabber 0.1.1 to nabnab 0.2.0 preserved the application data file byte-for-byte during installation. The installed executable matches the installer payload, and the installed application opened with a responding native window. No interface automation was used for this launch check.

External accounts, private course materials and real live-stream capture still require authorized live validation. Extractor support does not guarantee access to every operation or item. No DRM bypass, messaging, automatic account enrollment or access-restriction workaround is included.
